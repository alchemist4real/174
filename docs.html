DOKUMENTASI MR-CAPSULES

1. Apa Itu MR-CAPSULES?

MR-CAPSULES adalah platform edukasi non-profit yang didedikasikan untuk melestarikan dan membagikan pengetahuan akademis bagi mahasiswa. Dimulai pada Agustus 2025 dari sekumpulan file HTML sederhana yang dibagikan antar teman, kini MR-CAPSULES telah berkembang menjadi repositori belajar komprehensif.

Platform ini mewadahi catatan kuliah, bank soal (CBT), slide presentasi fakultas, dan berbagai sumber belajar akademis lainnya. Lebih dari sekadar arsip, MR-CAPSULES bertujuan menjadi "Tempat Belajar (Learning Sanctuary)" digital di mana mahasiswa dapat belajar, berkolaborasi, dan berkembang bersama.

2. Division Management (Manajemen Divisi)

Untuk menjaga kualitas dan keberlangsungan platform, kontribusi dibagi ke dalam beberapa divisi. Pembagian tugas ini dapat diatur melalui Admin Page.

  • Content Division: Bertanggung jawab mengumpulkan, menyusun, dan memelihara sumber belajar.
  • Correction Division (Review & QA): Bertanggung jawab meninjau bank soal, kunci jawaban, dan materi akademis.
  • Developer Division: Bertanggung jawab atas pengembangan platform, optimasi, dan implementasi fitur (HTML, CSS, JS).

Cara Membagi Tugas: Di halaman Admin, pengurus (Admin) dapat memilih profil pengguna dan menetapkan peran divisi (Division) yang sesuai. Setiap kontributor akan mendapatkan tanda pengenal (badge) sesuai dengan divisinya.

3. Division Development (Pengembangan Platform)

Bagi anggota Developer Division, pembuatan dan modifikasi konten sangat mengandalkan HTML, CSS, dan JavaScript murni tanpa framework rumit, untuk menjaga performa (Static Data Architecture).

  • Membuat HTML Baru: Gunakan template komponen yang sudah ada (seperti file bank soal CBT atau file notes). Pastikan struktur penamaan file HTML konsisten dan diunggah ke folder yang tepat (misalnya content/).
  • Merapikan Kode: Pastikan kode selalu rapi dan bersih. Anda bisa memanfaatkan CodeMirror yang terintegrasi di halaman Admin untuk mengedit dan mereview file secara langsung.
  • Alur Kontribusi: Melalui GitHub (Fork repositori, buat branch baru, lakukan perbaikan/penambahan HTML, dan ajukan Pull Request), atau menggunakan fitur unggah (Upload File) langsung melalui Admin Page bila diberikan akses.

4. Division Review & QA (Koreksi Konten)

Correction Division bertugas menjaga keakuratan materi akademis yang ada di MR-CAPSULES. Kualitas pembelajaran sangat bergantung pada kebenaran konten.

  • Review Konten HTML: Lakukan simulasi pengerjaan soal di mode CBT atau baca ulang materi catatan (Notes). Pastikan setiap penjelasan dan kunci jawaban sesuai dengan referensi perkuliahan yang valid.
  • Koreksi Kesalahan: Jika terdapat kesalahan (typo, referensi usang, atau salah konsep), catat nama file dan lokasi barisnya. Lakukan koreksi langsung melalui editor (jika memiliki hak akses) atau laporkan masalah ke tim terkait.
  • Kontak Developer Terkait: Jika terjadi masalah sistemik (bug UI, soal gagal dimuat, tampilan rusak di mobile, atau fitur tidak responsif), segera hubungi Developer Division melalui grup koordinasi untuk mendapat penanganan cepat.

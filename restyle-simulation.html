DOKUMENTASI GUIDE UMUM

Pengantar MR-CAPSULES

📖 ISTILAH PENTING:
  • Open-source = kode & pengelolaan terbuka, siapa saja boleh berkontribusi
  • CBT pool = bank soal pilihan ganda untuk latihan / ujian berulang
  • HTML = semua materi disimpan sebagai file .html interaktif

MR-CAPSULES adalah platform edukasi open-source untuk melestarikan & mendistribusikan bahan belajar kedokteran dalam satu tempat. Materi kuliah, praktikum, dan soal tahun lalu diubah menjadi basis data HTML pilihan ganda yang dapat dipakai ulang.

Pengenalan Admin Panel

Semua kontributor bekerja lewat Admin Panel dengan 4 fitur utama:

  • Dashboard — analitik, log aktivitas, leaderboard kontributor.
  • Files — file manager + HTML Editor dengan live preview.
  • Team — manajemen anggota divisi, broadcast, pengaturan global.
  • Tasks — Kanban board: Open → In Progress → Developed → In Review → Done.

Alur Kontribusi

  1. Ambil tugas di Task Board sesuai divisi kamu.
  2. Development meracik materi via AI prompt → HTML Editor → pindah ke kolom Developed.
  3. Review & QA cek live preview + kunci jawaban; lolos = Done, gagal = kembali ke In Progress.
MCP & API GATEWAY GUIDE

Integrasi AI Assistant

💬 INTINYA: MCP = NGOBROL, BUKAN CODING.
Cukup minta dengan bahasa biasa: "Buatkan task baru untuk Fisiologi Saraf blok 1.3". Claude otomatis menjalankan tools-nya di belakang layar.

Cara Mengisi API Key

  1. Buka Admin Panel → tab API Keys.
  2. Isi Key Name + masa berlaku, klik + Generate Key.
  3. Salin kunci mrc_... segera — hanya ditampilkan sekali.

Konektor Resmi

  • Claude.ai Web — Custom Connector → URL: /api/mcp (OAuth PKCE auto-discovery).
  • ChatGPT Custom GPT — Actions → Import OpenAPI: /api/openapi.json?category=essential (~24 tools).
  • Rate limit: 60 request/menit, maksimal 5 kunci aktif per pengguna.

Tidak perlu pengalaman coding

Alur kerja teknis dijelaskan setelah bergabung. Peran developer lebih ke Prompt Engineer — kode dibuat via AI dengan template yang sudah ada.

Pengurus & inovasi. Assign tugas di Kanban, kelola anggota di tab Team, siarkan pengumuman.

B. Development

Pembuat konten. Meracik materi mentah jadi HTML/CBT interaktif lewat AI + HTML Editor.

C. Review & QA

Korektor. Memastikan materi di kolom In Review bebas typo & salah konsep sebelum Done.
